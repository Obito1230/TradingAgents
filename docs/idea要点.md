# 论文 idea 要点

## 方向

面向多智能体交易辩论流水线的事件驱动三层记忆架构

## 定位

在框架 TradingAgents 之上,设计并验证一套   事件驱动的三层记忆系统   ,回答一个可验证问题——在有限上下文预算下,记忆系统能否让多智能体交易团队「记得住教训、用得上经验、不重复犯错」。

## 设计

（1）第一层：只对极端结算结果(超额收益或者意外亏损)触发,由复盘的agent 读全队辩论做出总结,写成精简结构化记忆。

（2）第二层：用确定性和按市场/资产定义的状态做相似度进行检索,只提取相关的记忆,省 token、防过拟合。

（3）第三层：记忆在被遗忘之前先蒸馏成团队准则，一定程度上挽回由遗忘带来的记忆缺失。

## 创新点

1. 复盘 agent 的输入是「全队辩论痕迹 + 结算语义」,现有反思都是自我反思,无同款;
2. 对遗忘机制的巩固闭环(淘汰→蒸馏→团队准则);
3. 比单层的性能更优的记忆系统

## 实验

配对 A/B(记忆开/关)+ 消融(关 L1 / 关 L3 / 检索阶梯),

指标 1.看添加此记忆架构之后方向判断有没有更准

2.加记忆后，收益本身有没有提升、稳不稳

3.看此记忆架构到底比原来的多花了多少token

总体的目标是在花得不多（甚至持平）的前提下，更准、更赚
