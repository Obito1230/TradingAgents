## 1. 一句话定位(对外口径)

> 在开源多智能体交易框架 **TradingAgents**(arXiv:2412.20138)之上,设计并验证一套**事件驱动的三层记忆系统**:L1 对极端结算结果(超额收益/意外亏损)做**基于全量多智能体辩论痕迹的事后复盘**并写入精简结构化记忆;L3 把被遗忘的记忆**先蒸馏成自包含、可修订的团队准则**再淘汰;L2 用**确定性、可量化、按市场/资产定义**的状态指纹做检索,控制注入内容。整体回答一个可验证问题:**在有限上下文预算下,记忆系统能否让多智能体交易团队记住教训、用上经验、不重复犯错。**

注意:以上是"系统级集成 + 实证结论"式定位,**不是**"提出了新的记忆机制"式定位。

**定位属性补充(架构口径):本文的贡献是架构级创新(新的组合与耦合),不是机制级创新。** 这是学界系统类论文的常规口径——GA / MemGPT / FinMem 本身都是架构贡献(检索打分、遗忘、反思等机制皆非其原创,贡献在"如何组合成可运行的记忆架构"),故表述为 **"为多智能体交易辩论流水线设计的记忆架构"** 是合法且标准的 claim 形式。

对外口径三句话:
1. 贡献是一套**记忆架构**(事件级复盘闭环 + 巩固式遗忘 + 状态检索的耦合),不声称任何单一记忆机制;
2. 架构中最稀缺的耦合点:**复盘 agent 以"全队辩论痕迹"为输入做事后归因**(现有反思均为自我反思,无已发表工作消费多 agent 讨论记录),配合结算语义(仅对极端 |alpha| 触发);
3. "更优"不是声明而是待证结论:由 P1–P5 消融 + 与 FinMem/GA/现基线的对照支撑(同等或更低注入预算下)。

**表述纪律**:机制名词(分层记忆/遗忘/反思/检索)一律归因已有工作;声称范围 = "这些机制以何种架构耦合、该耦合带来何种可测收益"——写论文/答辩时违反此纪律(如声称"提出新的遗忘机制")会被 FinMem/MemoryBank 直接击穿。

## 2. 相关工作对照表(直接回答"有没有人发过")

### 2.1 单机制对照:每个零件都有人发过

| 本文层/机制 | 最接近的已发表工作 | 该工作做了什么 | 我们的差异点(可声称的增量) |
|---|---|---|---|
| L1 事后复盘/反思 | **Reflexion**(Shinn et al., NeurIPS 2023);**TradingAgents 自带 reflection**(`reflection.py`) | Reflexion:把自评反思存入 episodic buffer 供下轮改进;TradingAgents:结算后写 2–4 句反思,但**只看到最终决策文本+收益数字** | 复盘 agent 的输入是**完整的多智能体辩论痕迹 + 结算结果**,回答"当时为什么这么决定、漏看了什么";且**只对 |alpha|≥阈值的事件触发**(稀有高价值采样),而不是对每条决策反思 |
| 分层记忆 + 遗忘 | **FinMem**(arXiv:2311.13743,ICLR 2024):交易 agent 的分层记忆 + 遗忘机制 + character 设计;**MemoryBank**(AAAI 2024):艾宾浩斯遗忘曲线;**MemGPT**(2023):OS 式分级上下文 | 单 agent、连续决策流上的记忆分层与遗忘 | ① 我们挂在**多智能体辩论框架**上;② 采样是**事件级**(结算期极端结果)而非逐日流式;③ 遗忘是"上限+保护集+淘汰分"混合,极端事件有**保护集**不被常规淘汰误杀 |
| L2 检索打分 | **Generative Agents**(Park et al., UIST 2023):memory stream 检索 = recency+importance+relevance 线性加权 | 通用生活模拟 agent 的记忆检索 | 我们用**域特定特征向量**(标的自身技术特征,按市场/资产定义)、**先逐维标准化再算余弦**、乘法门控而非三子分线性相加、粗桶降级;并**明确排除带符号结果加权**(GA/你早期方案的幸存者偏差问题) |
| L3 蒸馏出可复用准则 | **Generative Agents 的 reflection**;**Voyager 技能库**(把经验沉淀为可复用资产);记忆压缩理论([Rate–Distortion 视角](https://ar5iv.labs.arxiv.org/html/2607.08032):raw episodes → reusable knowledge) | 周期性/按需把细节提升为高层洞察或可执行资产 | **蒸馏挂在遗忘队列上**:先蒸馏、再淘汰(蒸馏补偿遗忘);增量式(上次准则+本批淘汰条目);准则自包含证据、可 `superseded_by` 修订;产物是可读的"团队准则"资产 |
| 多智能体 × 分层记忆(组合轴) | **TradingGPT**(arXiv:2309.03736,2023):multi-agent system with **layered memory** and distinct characters;**FinCon**(arXiv:2407.06567):多 agent + conceptual verbal reinforcement | 论文内 related work 点名(反思/记忆驱动的交易 agent) | **"多 agent + 分层记忆"的组合本身已存在** → claim 必须收敛到具体耦合(复盘输入=全队辩论痕迹+结算语义;蒸馏补偿遗忘闭环),不能声称组合层面新;细节写稿前精读原文核对 |
| 应用载体 | **FinMem/FinAgent**(交易记忆);TradingAgents 本体(决策日志,无分层) | 见上 | 我们以 **TradingAgents 的多市场/多资产**(US/HK/东京/印度/A股/加密)为实验场,而非单一美股组合 |

### 2.2 关键结论

1. **"精确组合"没有检索到已发表同款**,但组合不等于创新——审稿人会按上面每一格追问"和 X 有何不同";
2. **最需要主动对照的三组**:FinMem(单 agent 分层记忆交易)、**TradingGPT(多 agent × 分层记忆,2023 —— 组合轴最危险的邻近工作,来源:本框架论文 arXiv:2412.20138 的 related work 已点名)**、Generative Agents(检索+反思范式)——不主动对照 = 被当成不懂行;
3. 一个"意外利好":ESWA 综述《[Agentic Trading](https://ar5iv.labs.arxiv.org/html/2605.19337)》(2026,审计 77 篇)的结论是**该领域瓶颈是评估协议不可比**(19 篇核心实证中仅 2 篇报告时间一致切分、1 篇报告交易成本、0 篇达 R3 可复现)——**把评估协议做严谨本身就是可发表的贡献**,这是我们的主战场之一。

## 3. Claim 清单:能说 / 必须证明 / 绝不能说的

### 3.1 架构级 claim(本文主体;讲法是"新架构",不是"新机制")

架构 claim 的成立条件:**组合与耦合未以同形式发表过 + 每个设计决策有理由(消融或框架约束推导)+ 端到端更优在同等/更低预算下被证明**。可讲的架构内容:

- 把三层机制以**事件触发 + 保护集 + 蒸馏队列 + 检索门控**的耦合方式组装到 TradingAgents 的多智能体辩论流水线上;
- **核心耦合点(论文主线,二选一或双主线)**:
  ① 复盘 agent 以**全队辩论痕迹 + 结算语义**为输入的事件级事后归因(现有反思均为自我反思,无同款);
  ② **蒸馏补偿遗忘的巩固闭环**(淘汰→蒸馏→自包含可修订准则,配保护集保极端事件);
- 面向多市场/多资产的特征集与检索定义(架构约束推导:无组合概念→标的自身特征;跨市场→按市场定义特征集)。

**命名建议**:给架构一个名字(如 *Consolidation-Gated Event Memory*),让审稿人/评委讨论的是"你的架构",而不是"凑了三层"。

### 3.2 必须实验证明的实证 claim(论文的主体)

- **P1(消融-必要性)**:关闭 L1(回到现基线"平权 2–4 句反思")后,决策质量下降 —— 证明复盘闭环有用;
- **P2(消融-补偿)**:关闭 L3(只淘汰不蒸馏)后,跨期一致性/准则可读性下降 —— 证明蒸馏补偿遗忘有效;
- **P3(L2 消融阶梯)**:`(A) 纯相似度 → (B) 相似度×recency^γ → (C) vs 同 ticker 最近 n 条平权`——证明状态检索优于平权注入;τ/K/γ 的敏感性;
- **P4(预算论据)**:同等或更低注入 token 预算下取得 P1–P3 的提升 —— 呼应"记忆膨胀的成本曲线"动机;
- **P5(质量)**:复盘摘要人工评估(是否抓住真正原因、可迁移性)。

### 3.3 绝不能声称是新的(写了会被直接拒)

- ❌ "提出分层记忆/多级记忆" —— FinMem/MemGPT 已做;
- ❌ "提出遗忘机制/艾宾浩斯式遗忘" —— MemoryBank 已做;
- ❌ "提出反思/自我进化" —— Reflexion/GA 已做;
- ❌ "提出按 recency+importance+relevance 检索" —— GA 已做;
- ❌ "提出把经验蒸馏为高层准则" —— GA reflection / Voyager 已做。

## 5. 比赛作品路线(先交付可演示的东西)

- **核心演示对象是 v1(L1)+ 部分 v2(L3)**,做成"记忆系统在运转"的可见过程,而不只是一次分析结果:
  - 仪表盘可视化:记忆条目库(卡片流)、事件触发的复盘过程(结算 → 阈值命中 → 复盘 agent 读辩论全文 → 结构化摘要落库)、遗忘与保护集动画、蒸馏准则面板(可读、可修订)、当前 run 注入内容预览(top-k 与准则 preamble);
  - 对比视图:同一 (ticker, date) 开关记忆系统,展示注入内容差异与决策文本差异;
- **技术贡献陈述口径**:增强开源多智能体交易框架的记忆能力(见 §3),不声称发明新机制;
- 比赛申报材料 = 作品 + 演示视频 + 技术文档(本文档 + 设计文档即技术文档底稿);
- 注意:基础框架开源可放心用,但**作品的技术主体与"新在哪"必须落在记忆系统本身**。

## 6. 论文评估协议草案(比赛与论文共用,先定协议再攒数据)

> 依据 ESWA 综述的审计结论,协议严谨性本身是卖点。逐项写明:

1. **配对 A/B**:固定 (ticker, date) 列表(日期足够靠后、收益已实现可确定性取得),记忆开/关各跑 N≥5 轮(LLM 采样噪声,单次无效);
2. **时间一致切分**:模型选择/参数(τ/K/γ)调优只在训练期日期上做,测试期日期绝不参与任何调参;
3. **交易成本**:统一声明(如无成本模型则显式说明,不假装精确);
4. **幸存者处理**:实验 universe 的入选/剔除规则写明(用当时已上市的标的集合,说明 delisted 标的的处理);
5. **指标**:方向命中率、模拟 alpha(均值/方差)、注入 token 预算、复盘摘要人工质量分;统计检验(配对 t/符号检验)而非只看均值;
6. **消融阶梯**:§3.2 的 P1–P5;
7. **可复现**:固定 provider/模型档位/温度、种子、数据版本;release 代码 + 实验配置;
8. **预算现实**:全链路一次 run 含十几个 LLM 节点 → 消融先用 quick 档模型跑通,结论复现用 deep 档;总调用预算在实验前定上限。
