# 论文 idea 要点(EI 会议)

## 题目方向

面向多智能体交易辩论流水线的事件驱动三层记忆架构

## 一句话定位

在开源多智能体交易框架 TradingAgents 之上,设计并验证一套**事件驱动的三层记忆系统**,回答一个可验证问题——在有限上下文预算下,记忆系统能否让多智能体交易团队「记得住教训、用得上经验、不重复犯错」。

## 三层设计

- **L1 事件记忆**:只对极端结算结果(超额收益 / 意外亏损)触发,由复盘 agent 读全队辩论痕迹做事后归因,写成精简结构化记忆。
- **L2 状态检索**:用确定性、按市场/资产定义的状态指纹做相似度检索,只注入最相关的记忆,省 token、防过拟合。
- **L3 准则蒸馏**:记忆被淘汰前先蒸馏成自包含、可修订的团队准则(「巩固式遗忘」)。

## 创新点(架构级创新,非机制级)

1. 复盘 agent 的输入是「全队辩论痕迹 + 结算语义」,现有反思都是自我反思,无同款;
2. 「蒸馏补偿遗忘」的巩固闭环(淘汰→蒸馏→可修订准则);
3. 把评估协议做严谨(时间一致切分、交易成本、配对 A/B + 消融),本身即贡献。

## 实验

配对 A/B(记忆开/关)+ 消融(关 L1 / 关 L3 / 检索阶梯),指标 = 方向命中率、模拟 alpha、注入 token 预算。
